다크 모드를 구현하는 가장 깔끔한 방법은 **색을 전부 CSS 변수로 관리**하는 것입니다. 컴포넌트는 변수만 참조하고, 테마가 바뀔 때는 변수 값만 바꿉니다.

## 두 가지 조건

다크 모드가 켜지는 경우는 두 가지입니다.

- 사용자가 직접 다크 모드를 고른 경우
- 아무것도 고르지 않았고, 운영체제가 다크 모드인 경우

```css
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --bg: #0f1115; }
}
:root[data-theme="dark"] { --bg: #0f1115; }
```

`:not([data-theme="light"])` 덕분에 시스템이 다크 모드여도 사용자가 라이트를 고르면 라이트로 보입니다.

## 깜빡임 막기

JavaScript 모듈은 페이지가 그려진 뒤에 실행되기 때문에, 저장된 테마를 그때 적용하면 화면이 잠깐 번쩍입니다. 그래서 `<head>` 안에 아주 짧은 인라인 스크립트를 두고 렌더링 *전에* 테마를 적용합니다.
